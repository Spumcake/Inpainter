# Inpainter

From this directory, with Rust 1.95, build the host and the demo:

```
cargo build
```

Both binaries land in `target/debug`.

Open the window:

```
cargo run -p inpainter
```

The window is titled Inpainter. It has a Demo tab, an empty toolbar, a grid, and a panel tab on the right. The menu button, the plus, and the tab's close mark do nothing. The panel tab opens and closes an empty column.
